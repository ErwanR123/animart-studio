# Museum Companion — Navigation & Information Architecture

## Core loop
Discover → Visit → See real art → Learn/experience → Collect → Connect to history → Play/reinforce → Unlock → Explore again.

## Bottom navigation
**Accueil — Explorer — Visite — Carnet — Profil**

### Accueil
“What can I discover today?” Dynamic modules: continue active visit, nearby/planned museum, recommendations, current historical chapter, recent discovery, contextual challenge. Do not become an infinite feed.

### Explorer
“What is around me / what can I visit?” Map + list. Museums, exhibitions, monuments and cultural places. Explorer is about the **real world**.

### Visite
“Guide me through what I am experiencing now.” When active: current artwork, audio, map, route, next stop, Ask the Guide, scan/identify, pause/exit. During visits, reduce screen attention and favor audio.

### Carnet
“What have I discovered and what story am I building?” Top areas: `Histoire | Œuvres | Lieux | Collections`. Carnet is about the **user's cultural world**.

### Profil
Identity, explorer level/descriptor, stats, badges, visited museums, history, favorites, downloads, preferences and settings. Visually quiet.

## Museum detail
Hero, museum name/location, practical info, exhibitions, highlights, collections, possible routes, user's museum progress. CTA: Planifier / Commencer la visite.

## Artwork flow
Photo → recognition → reveal → Guide reaction → listen/read/immersive content → notebook update → historical connection → continue visit.

## Artwork detail
Image, title, artist, date, location, listen/save/share. Tabs: `À propos | Contexte | Anecdotes | Connexions`.

## History structure
Human History → Period → Chapter → Event/idea/person/movement → artwork/object/place → user discovery. User discoveries illuminate the shared historical structure.

## Mini-games
No permanent tab. Entry points: Home challenge, Notebook chapter, post-visit recap, artwork discovery, collection completion, Guide suggestion. Flow: Context → Challenge → Interaction → Answer → Explanation → Reward/progress → relevant Notebook context.

## Guide semantics
Home: suggests. Explorer: encourages. Visit: guides. Artwork: explains. Carnet: connects. Games: challenges. Profile: rarely appears.

## Navigation rule
Before adding a tab ask: “Is this somewhere the user wants to go, or something the user wants to do?” Actions such as scan, audio and games do not deserve permanent destinations.
