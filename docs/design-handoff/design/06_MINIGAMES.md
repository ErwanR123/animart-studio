# Museum Companion — Mini-games

## Purpose
Mini-games reinforce cultural understanding and memory. They should feel like playful manipulation of the user's Explorer Notebook, not a separate arcade mode.

## Entry points
- Home contextual challenge
- Notebook chapter
- Post-visit recap
- Artwork discovery
- Collection milestone
- Guide suggestion

No permanent bottom-navigation tab.

## Design principles
- Prefer content the user has actually encountered.
- Every answer should teach or reinforce something.
- Short sessions; museum usage must remain calm.
- Wrong answers are informative, never punitive.
- Rewards should update the Notebook or reveal context rather than grant arbitrary currency.

## Canonical games
### Artwork Detail
Show a crop/detail. Ask which artwork it belongs to. 3–4 plausible choices. After answer, explain the visual clue.

### Timeline
Reorder discovered works/events chronologically. Support drag-and-drop plus tap-based accessible controls. Explain temporal relationships after validation.

### Matching
Artwork↔movement, artwork↔artist, artwork↔event, person↔period, place↔event. Use clear connection lines/cards.

### Odd One Out
Four works/items; three share a learned property. Ask which differs, then explain the concept.

### Artwork Puzzle
Reassemble a small number of visual fragments. Keep short; purpose is visual familiarity, not puzzle difficulty.

### Quick Quiz
One question per screen with strong imagery and minimal chrome. Use for mixed reinforcement.

## Game shell
Top: back/close, progress, optional restrained lives/attempt indicator only if it improves the mechanic. Middle: cultural content/question. Bottom: answer controls/validation. Guide stays small unless introducing or reacting.

## Feedback
Correct: concise celebration + why it is correct. Incorrect: “Pas tout à fait…” + visual/contextual clue + explanation. Do not flood the screen red.

## Completion
Show concise result, concepts reinforced, Notebook impact/unlock and a CTA to the relevant chapter/collection. The Guide can celebrate.

## Visual language
Paper cards, artwork fragments, stamps, connecting lines, timeline strips, subtle torn-paper edges. Stay within paper/terracotta/olive/ochre/ink. No arcade gradients, neon, coins or trophy chests.
